Sigma58 -- PROMOTED TO TRACK A BASELINE 2026-07-30, PROVENANCE CAVEAT BELOW
- Architecture:
	- Same core name-book as the Sigma18/19 chassis (seed pairs, gray tier GW=0.5, birth-catcher off/BIRTHW=0) plus a spectral-shrunk 90/10 blend of expanding-history and recent-window lead-lag matrices (base + a 10-day aggregate variant), an ALGO-shock-conditional lead vector, a causal-reliability-gated architecture selector (single/split-committee/cross-fit-committee modes via _ARCH_RELIABILITY_LOWS/HIGHS), a cross-fitted lead-lag reliability vote, a ridge-regression basket mean-reversion sleeve (8 nearest-correlation peers per name), and an extreme-residual reversal overlay
	- Independent second "guard" engine (relationship-decay-focused) blended in: only overrides the primary engine's position for a name when the guard's own signal has changed from its last base call
	- Portfolio-level circuit breaker overlay: scales the WHOLE book's size (never direction) 1.0x down to a 0.4x floor based on the strategy's own trailing 60-day realized Sharpe; provably inert on every real window checked (never fires across days 1-1000)
- Exposure:
	- ALGO hedge off; adaptive selector picks between a plain 5-day reversal and a relative-basket reversal, full $100k cap
- Performance (continuous 501-1000 is this project's primary/correct scoring metric, per entry 50's metric-bug fix -- see Alpha Exploration Log):
	- Days 251-500: 883.34
	- Days 501-750: 1140.24
	- Days 751-1000: 1005.95
	- Days 501-1000 (continuous, primary): 1033.71

POST-PROMOTION AGENT-7-LEVEL AUDIT (2026-07-30, see Alpha Exploration Log entry 16): the full `validate_overfitting.py` robustness audit (same suite already run against Sigma58) was re-run against Sigma59, using Agent 7's exclusive clearance to `prices_full_final.txt` -- this was a one-shot post-hoc check of an already-decided, already-promoted candidate, not used to guide any further tuning choice, so it does not repeat the Sigma20-58 lineage's selection-bias pattern. Result: Agent 3's watch item was directionally confirmed on the one genuinely fresh window neither Agent 1 nor Agent 2 could ever see -- Sigma59 scores WORSE than Sigma58 on both days 751-1000 (1005.95->988.26, -1.76%) and the continuous 501-1000 window (1033.71->1025.54, -0.79%), i.e. the exact improvement Sigma59 was promoted for does not generalize to the fresh holdout. No other audit component shows new red flags: concentration profile, leave-one-block-out range, mechanical-stress-test shape, placebo-test levels, and relationship-decay curve are all essentially unchanged from Sigma58's own audit (see `validation_output/validation_summary.txt` for Sigma58 vs `validation_output_sigma59/validation_summary.txt` for Sigma59). One new, localized signal: parameter-neighbourhood standard deviation increased specifically for the two basket-sleeve-adjacent constants touched by this change's neighbourhood (`_primary_BASKET_ALPHA` sd 4.71->7.19, `_primary_BASKET_GATE` sd 2.05->8.49), while every other tested constant's sensitivity stayed roughly flat -- consistent with the ridge change having moved the basket sleeve into a locally less-flat part of its own parameter space, even though it didn't blow up any single other diagnostic. Net read: not a catastrophic overfit (no cliff, no exploding concentration/placebo/decay signal), but a genuine, now-confirmed instance of Agent 2/3's regime-fragility caveat -- the specific edge this promotion was built on does not hold on the one window it was never allowed to see. Not yet tested live.
